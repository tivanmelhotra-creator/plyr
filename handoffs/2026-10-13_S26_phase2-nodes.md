# S26 — phase 2 (nodes on the profile infrastructure), branch feat/profile-infrastructure (PR #76)

No parallel system was built: everything goes through the existing pipeline, ErrorPolicy,
ProfileLeases (ADMIT_LUA + grant), BrowserSessions and RunPolicy.

## Done
1. Node settings (Launch Browser): `profileId` param = this node's profile (empty = workflow's).
   core/NodeProfile: one profile per run; the worker's lease, reservations (ProfileCoordinator) and
   delete-blockers use it; Launch nodes naming DIFFERENT profiles are refused by validateSteps.
   Visibility override = the existing per-node `headless` browser option (RunPolicy default otherwise).
2. Success / Error / Timeout outputs for every non-control-flow node: Settings -> "Success / Error /
   Timeout outputs" adds `error` and `timeout` ports (`next` = Success). Serialized as
   `errorSteps` / `timeoutSteps` (nested groups, same validation + every walker updated:
   TestRunGate, BrowserOptions, ActivationCheck, live-tab, workflow-exchange, pipeline nodeSlot).
   Runtime (core/NodeOutputs): failure after retries -> branch with ONE item
   {error(first line), kind, node, attempts}, then the group is left (like an `if` path);
   timeout without a Timeout output -> Error output; fatal control flow never routes.
3. Retry policy per node: retryOn any|error|timeout, retryBackoff linear|fixed|exponential
   (ErrorPolicy.failureKindOf / retriesKind / backoffDelayMs), node timeout `timeoutMs`
   (Playwright default timeouts for that step; module steps via withStepTimeout).
4. Continue Session node (`continue-session`): core/SessionContinuation. ONLY via
   ProfileLeases.grant(profile, fromOwner, toOwner, ttl) + BrowserSessions dependent `grant:<to>`.
   The worker passes leaseToken + owner; only the lease holder can grant; target must exist;
   ttl 1 min..6 h (default 15); consumed (revokeGrantsTo) when the target's run on that profile ends;
   expired grants swept every minute. Without the node nothing is shared.
